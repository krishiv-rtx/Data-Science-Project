## 11. DESIGN THREE TO FIVE HYPOTHESIS TESTS

Conduct 3–5 valid, nonredundant hypothesis tests on the actual data.

Four tests are a reasonable initial target if the data supports them.

The following are candidate designs. Select and finalise the tests only after verifying the actual columns, sample sizes, and assumptions.

### Candidate Test A: Interest-rate difference

Question: Do interest rates differ between Fully Paid and Charged Off loans?

Potential test: Welch's independent two-sample t-test.

Possible estimand: mean interest rate among Charged Off loans minus mean interest rate among Fully Paid loans.

Use the original percentage-point scale for the main estimate when appropriate. Investigate skewness, group sizes, and the distribution of interest rates.

### Candidate Test B: Debt-to-income difference

Question: Does the debt-to-income ratio differ between Fully Paid and Charged Off loans?

Potential test: Welch's independent two-sample t-test, provided the data definition and sample sizes justify its use.

Inspect extreme values, missingness, and whether the groups differ substantially in spread.

Consider a log or robust sensitivity analysis only if the variable's domain and the scientific question justify it. Do not use a log transform on negative values without a defensible handling rule.

### Candidate Test C: Loan-grade association

Question: Is recorded loan grade associated with terminal repayment outcome?

Potential test: chi-square test of independence using a properly defined contingency table.

Specify the included outcome categories and grade categories.

Calculate expected cell counts and assess whether the chi-square approximation is suitable.

If expected counts are inadequate, use a defensible alternative or combine categories only when substantively justified. Explain the choice.

Report degrees of freedom, test statistic, p-value, and an interpretable measure of association where appropriate.

### Candidate Test D: Loan-term and charge-off proportion

Question: Does the observed charge-off proportion differ between eligible loan-term groups?

Potential test: a two-proportion z-test if the groups and denominator definitions are valid and the approximation conditions are satisfied.

Restrict the denominator to the explicitly defined eligible population, such as loans with terminal outcomes, if that matches the research question.

Define charge-off as the success or event indicator consistently.

Report both observed proportions, their absolute difference in percentage points, the confidence interval for that difference, and the test result.

A chi-square test on the equivalent 2 × 2 table may be reported as a cross-check. Explain the relationship between the methods and avoid counting the same test twice as two independent research findings.

## 12. STATISTICAL CORRECTNESS RULES

These rules are mandatory.

1. Never invent numerical results.
2. Never report a p-value from an unexecuted calculation.
3. Never infer a test result from a graph alone.
4. Never say that failing to reject H0 proves H0 true.
5. Never equate statistical significance with practical importance.
6. Never claim that a small p-value establishes causation.
7. Never use a paired t-test for unrelated groups.
8. Never use a pooled t-test without addressing its equal-variance assumption.
9. Never use a z-test requiring a known population standard deviation when only the sample standard deviation is available.
10. Never use a two-proportion test without clearly defining the two populations and their denominators.
11. Never use a chi-square test of independence on arbitrary numerical measurements instead of suitable categorical counts.
12. Never use the same observation as independent evidence multiple times without acknowledging dependence.
13. Never ignore the problem of multiple testing when conducting several related tests.
14. Never select a one-sided alternative after inspecting the direction of the observed difference.
15. Never report zero as a p-value. Use a suitable scientific-notation value or an appropriate bound.
16. Never confuse the standard error with the standard deviation.
17. Never treat a confidence interval that includes zero as proof that the true effect is exactly zero.
18. Never interpret a large sample size as a guarantee that every approximation or assumption is valid.
19. Never describe current loans as completed outcomes.
20. Never allow a post-origination feature to leak into a model intended to predict outcomes at origination.

### Confidence intervals

Calculate 95% confidence intervals using the correct formula or a well-tested statistical implementation.

For a difference in means, report the difference in the chosen direction and the corresponding interval.

For a difference in proportions, report the absolute difference in percentage points and an appropriate interval for two independent proportions.

For a categorical association, report an interpretable effect measure and uncertainty interval when feasible.

Check the interval against the test result for consistency.

If an interval and a hypothesis-test conclusion disagree unexpectedly, investigate the implementation rather than reporting both.

### Multiple testing

Because the project includes several related tests, explain the implications of repeated testing.

Use the unadjusted tests as the primary analysis if appropriate for the course and research design, but clearly label them.

Where several related hypotheses form one family, consider Holm adjustment as an optional extension. Report both adjusted and unadjusted results if you implement it.

Do not silently change the significance threshold after observing the results.

### Alternative tests

Make the comparison specific to the question.

For example, when considering an independent two-sample mean comparison, explain why a two-sample z-test, pooled t-test, Welch t-test, paired t-test, or a correlation test may or may not fit the design.

Do not mechanically list every test taught in the course. Discuss genuinely plausible alternatives.
